# Contributing Guidelines

Thank you for your interest in contributing to `flutter_cache_avatar`! 

To ensure the quality of the codebase and the stability of the library, please follow the contribution process outlined below:

## 1. Report Bugs
If you find a bug while using the library, please open an **Issue** on GitHub.
Please include:
- The Flutter version you are using.
- A minimal code snippet to reproduce the issue.
- Detailed error logs (if applicable).

## 2. Feature Requests
If you have an idea for a new feature, please open an **Issue** so we can discuss it before you start coding. This helps ensure the feature aligns with the library's roadmap.

## 3. Pull Requests
This repository does not allow direct push access. To contribute code, please follow these steps:
1. **Fork** this repository to your GitHub account.
2. Clone your forked repository to your local machine.
3. Create a new branch for your feature or bug fix: `git checkout -b feature/your-feature-name`.
4. Write your code and ensure it introduces no analyzer warnings (`flutter analyze` should return 0 issues).
5. Push the branch to your forked repository.
6. Open a **Pull Request (PR)** from your fork to the `main` branch of the original repository.
7. Wait for a review and merge.

Thank you very much for your support!
